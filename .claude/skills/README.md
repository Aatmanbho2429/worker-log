# Project skills

Empty for now. Add a project-specific skill here as
`.claude/skills/<skill-name>/SKILL.md` when a multi-step procedure in this repo
gets pasted into chat more than once — e.g. a barcode-sheet regeneration
checklist, a Supabase edge-function deploy flow, or a demo-data reset routine.

See https://code.claude.com/docs/en/skills for the frontmatter format
(`description`, `disable-model-invocation`, `paths`, etc.) and
`.claude/rules/` (sibling directory) for standing conventions that should just
always be in context rather than invoked as a procedure.
